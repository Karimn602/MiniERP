## What changed

**Only the About box.** Click the version number in the sidebar. It now reads:

> Developed by Omar Najjar
> Software Engineering & Business Solutions
> LinkedIn: View Developer Profile

**View Developer Profile** opens
`https://www.linkedin.com/in/omar-s-najjar-1b7994259/` in the computer's
default web browser. The till window itself never navigates away. The link
opens through a command that takes no input and can open only that one
address, and the screen holds no permission to open anything else.

The credit appears in the About box only. It is not on receipts, kitchen
tickets or the Register. It is shown in both editions.

No business rule, posting command, migration or database change. Installing
1.1.1 over 1.1.0 keeps the database and applies no migration. Installing it
over 0.1.0 does what the 1.1.0 notes describe (migration 025); read
`docs/V1.1-RELEASE-NOTES.md` for that upgrade, and take the operator backup first.

Also in this commit, test-only: one Register test that failed about one run
in six on the 1.1.0 source now waits for the menu to load.
